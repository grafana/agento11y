# Git remote fixtures

`remotes.tsv` is the shared contract for the `repo` automatic tag. Four implementations reduce a checkout's `origin` remote URL to that tag, and each one's tests read this file and must give the `want` column for every row:

| Plugin | Function | Test |
|---|---|---|
| agento11y (Claude Code, Codex, Cursor, Copilot and the other Go hooks) | `repoFromRemoteURL` in `plugins/agento11y/internal/gitbranch/gitbranch.go` | `TestRepoFromRemoteURLCorpus` |
| pi | `repoFromRemoteUrl` in `plugins/pi/src/git.ts` | `plugins/pi/src/git.test.ts` |
| opencode | `repoFromRemoteUrl` in `plugins/opencode/src/git.ts` | `plugins/opencode/src/autotag.test.ts` |
| Hermes | `_repo_from_remote` in `plugins/hermes/src/agento11y_hermes/_tags.py` | `plugins/hermes/tests/test_tags.py` |

The file is tab-separated with a header row. The columns are:

| Column | Contents |
|---|---|
| `url` | The remote URL as `git config remote.origin.url` prints it. |
| `release` | What agento11y v0.57.0 gave for the URL, generated by running that release's `repoFromRemoteURL` from a checkout of the tag. Do not edit it by hand. |
| `want` | The tag every implementation must give now. |

Rows where `want` differs from `release` are label changes for users. Add a row for any remote form an implementation starts to treat specially, and say in the pull request which rows changed.

Rows are read on a POSIX platform: `C:/repos/agento11y.git` is an scp-style remote to host `C` there, and a Windows drive path only on Windows.
